Germinate provides built-in visual analytics to explore relationships across passport, phenotypic, and genotypic domains.

## Available Views

* **Geographic Maps**: Cluster and filter collecting sites or trial locations on interactive world maps.
* **Trait Distributions**: Boxplots, histograms, and scatter plots comparing trait performance across trials or subgroups.
* **Matrix & Heatmap Views**: Visual summaries of data completeness and multi-trait correlations.

## Export Formats

Filtered datasets can be exported in standard formats including **CSV**, **Excel**, **MCPD**, and **Flapjack** project files for downstream statistical analysis in R or Python.
