The settings page lets administators make major changes to the Germinate configuration. These mirror the settings on the <a href="{{ '/admin/configuration' | relative_url }}">Germinate configuration</a> file. The settings page can be reached through the main navigation's `Advanced settings` section or through the user dropdown in the top bar.
